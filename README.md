# 律动星轨

一个网页版的四轨下落式音乐节奏游戏。纯静态页面，没有依赖，也没有音频文件——所有音乐都由浏览器用 Web Audio 实时合成。

## 怎么玩

双击 `index.html` 即可，或者起一个本地服务器：

```bash
python -m http.server 5437
```

- `D` `F` `J` `K` 击打四条轨道，手机 / 平板直接点击轨道
- 长条音符要按住到结束再松开
- 连续命中攒满能量后按 `空格` 释放 Fever，8 秒内得分翻倍
- `Esc` 暂停

判定窗口：Perfect ±50ms、Great ±100ms、Good ±150ms。总是偏早或偏晚时，在「设置」里调判定偏移。

## 加一首歌

在 `js/songs.js` 里按文件开头的记谱格式写旋律和和弦，伴奏（贝斯、和声、鼓）和三档谱面会自动生成。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `js/songs.js` | 曲库：旋律、和弦、段落强度 |
| `js/music.js` | 把曲谱编译成带伴奏的音频事件表 |
| `js/chart.js` | 根据旋律生成三档谱面 |
| `js/audio.js` | Web Audio 合成器与播放调度 |
| `js/game.js` | 判定、计分、Fever、Canvas 渲染 |
| `js/main.js` | 选歌、设置、暂停、结算与成绩存档 |
